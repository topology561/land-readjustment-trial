# 術語與示意圖之幾何（市地重劃·本案之用語）

> 依據：`K-6` 典、`.claude/skills/cad-layer-semantics`、`corner-selection-rules`、手冊拾貳與拾柒；KL 之歷次指正。用語以本檔為準，⛔ 自創同義詞。

## 一、空間之物

| 詞 | 定義 | 易錯處 |
|---|---|---|
| 重劃區 | 本案之範圍；區界外之地⛔ 參與配地 | 區界可落在道路中心線（`K-9-79`） |
| 街廓（BLOCK） | 四周以道路（或區界）圍成之可建築或公設之區塊；CAD 之 `BLOCK` 多邊形 | **兩個街廓之間必隔道路**（或屬同一實體街廓之分切而以 JOINLINE 相接）；⛔ 畫成兩街廓直接相鄰 |
| 道路 BLOCK | 道路本身之多邊形；每條道路一條 `CENTERLINE`，於路口分割（`K-9-59`） | 道路上之重劃前土地＝「道路片」 |
| 路口片 | 臨三個以上街廓之道路片；按面積平分（`K-9-59`）；`JUNCTION` 為選用之框 | — |
| 正面道路／正街 | 街廓臨之主要道路；`FRONTLINE`（檔名 FRONTLINE）沿之 | 線畫到**未截角之理論尖角** |
| 側面道路／側街 | 街角處與正街交會之道路；`SIDE_LINE`（檔名 **SLIDE_LINE**，KL 慣用拼法） | — |
| 截角 | 街角處視距截去之三角；BLOCK 邊停在截角 | — |
| BASELINE（屁股線） | 街廓後緣之線；每宗必配到 BASELINE（`K-9-4`）；一條可服務 1〜N 街廓 | 不支援同一街廓前後兩排 |
| ALLOC_LINE（分配線） | 街廓內一切方向之權威；宗地寬度 ⊥ALLOC 量 | — |
| JOINLINE | 同一臨街面因折線或圓弧而分切之相鄰 BLOCK 之接續線（`K-9-63`） | L 形街廓⛔ 用 JOINLINE（分兩 BLOCK、依 `K-9-4-1` 設末端塊） |

## 二、宗地與配地

| 詞 | 定義 |
|---|---|
| 宗、重劃前土地、地號 | 重劃前之地籍單位；「暫編地號」為程式內之編號（字典序比較） |
| 歸戶 | 同一所有權人（或同組共有）之土地之集合；`U_LAND` 工作表 |
| 原位次 | 重劃前土地沿正街之投影順序；配地按原位次自街角向內推進 |
| 街角地 | 位於街廓之角、**同時臨正面道路與側面道路**之宗；「街角第 1 宗」須寬 ≥ 退縮寬＋畸零地最小寬、G ≥ 街廓最小建築面積（`K-9-1`、`K-9-5`） |
| 街角規定範圍 | 街廓內距側街 ≤ T（T＝街角退縮＋法定最小畸零地寬）之帶；其面積即街角最小分配面積 |
| G、應分配面積 | 重劃後應分配之面積（依負擔計算）；比較時以 `0.01 ㎡` 為單位（`k967_rank`） |
| 最小分配面積 | 原街廓原路街線最小分配面積標準；未達二分之一者現金補償（手冊拾貳） |
| 畸零地最小寬、最小深度 | 花蓮縣畸零地使用規則附表；`K-9-6` |
| 末端塊（R_end） | 街廓兩端推進交會處之剩餘塊；`K-9-36`、`K-9-49`、`K-9-50`、`K-9-60` |
| 合併再試 | 單筆未達街角或原位次之門檻時，併同一地主相連之宗再試（段三） |
| 手冊先行（手冊併入） | 分不到之宗併入同一地主已配得之宗（`K-9-53` ①）；本街廓優先（`K-9-55`） |
| 入池閘 | 合併後能原位配者處理之閘（`K-9-29` 六、`K-9-58`） |
| 調配、調配池 | 分不到之土地合併單位入他處增配或現金補償（`K-9-35`〜`46`）；原街廓之擇依 `K-9-46`、`K-9-61` ⑧ |
| 抵費地 | 重劃後由主管機關取得、標售抵費用之地；強制抵費地＝街角無人合格時之第 1 宗 |
| 抵充地 | 重劃前之既成道路等公有地，抵充公共設施用地（`K-9-62` 二欄） |
| 臨街地特別負擔 | 正面／側面道路負擔＝線長 × 尺度（`K-9-74`、`K-9-79`） |
| 退縮 | 本案兩情境：3.5 m 與 0 m；驗收須二退縮皆過 |

## 三、示意圖之畫法（請示 KL 之圖·⛔ 違）

1. 每一街廓四周畫出道路（灰帶）並標路名或「正面道路」「側面道路」；**街廓與街廓之間一定有道路**。
2. 街角地畫在街廓之角，**同時貼著正面道路與側面道路**；兩條路都要畫出。
3. 每一宗標：地主（甲、乙）、地號、應分配面積（㎡）、是否原位次配得。
4. 道路片畫在道路之中，以中心線（虛線）分屬兩側；路口片畫在路口。
5. 同一地主之宗用同一顏色；未配得者用淺色。
6. 箭頭表示「併入」之去向；甲案、乙案用不同顏色並在圖下以文字寫明。
7. 圖成之後自查：「這張圖在真實的都市計畫圖上可能出現嗎？」有任何一宗只臨一條路卻叫街角地、或兩街廓直接相貼，即錯。
8. ⛔ 程式術語（閘、k、ΣRw 等）入圖；用土地之語（街廓、地主、抵費地、面積）。
