# 市地重劃發單（發單端之知識庫）

本 skill 濃縮八十餘窗之累積，使每一輪不必從 83 萬字之 `K-6` 典讀起。**它是索引與方法，不是裁示本身**：裁示之權威仍是倉內 `K-6` 典之逐字，手冊之權威是手冊原文；本 skill 告訴你去哪裡找、怎麼做、哪些坑不要再踩。

## 開工之序（每輪）

1. 讀 `ops/queue` 之 README、`發單端.md`、`STATE.json`、`交接.md`、`log.md` 末段（同 `發單端.md` 甲）。
2. 讀本檔全文（約 5 分鐘），再依手上之事讀下表之參考檔。
3. 結束前於 `retro.md` 末追加本輪之坑或捷徑（一至三列）。

| 手上之事 | 先讀 |
|---|---|
| 判斷某情形是否已有裁示 | `丁類34題對照.md` → `裁示索引.md` → `K-6` 典該列之全文 |
| 涉道路、公設、街角、共有、最小分配面積、集中分配、調配 | `手冊索引.md` → 手冊原文（`/tmp/q/參考/市地重劃作業手冊.txt`） |
| 畫示意圖、寫請示 | `術語與幾何.md` 第三節、`與KL溝通.md` |
| 擬規格單、補令、復驗 | `擬單與復驗.md`；倉內 `docs/orders/` 之範本 |
| 用語不確定 | `術語與幾何.md` |

## 十戒（最常重犯·違之者 KL 已指正過）

1. **已裁勿問**：丁類 34 題已全數定案（`K-9-57`〜`63`）；手冊已明者亦勿問。請示前列出所查之條與其何以不及。
2. **街廓之間必隔道路**；**街角地必同時臨正面道路與側面道路**。示意圖違之即錯。
3. 結論前讀完正典之全文，含其後之讀法、更正、作廢註（同號以 `grep -n "K-9-NN"` 全檔查）。
4. ⛔ 採信執行端之自報；一切以倉內實物與自己之重跑為準。
5. 閘綁其所保之性質，附對照組證其可紅；「零命中」須窮盡同義詞並記母體。
6. 浮點設界須附容差與其依據；缺值、讀檔例外、缺表須列錯誤，⛔ 靜默。
7. ⛔ 寫死街廓名、側別、本案常數（他案必用）。
8. 他案可能遇之情形現在列舉、現在處理（KL 2026-10-05：⛔「遇到再停」）。
9. ⛔ 令雲端之執行端寫 `CLAUDE.md`；推單前重讀 `STATE.json`；擬單先上 `drafting` 鎖。
10. 一輪持續做到出單、復驗畢或請示，⛔ 做一小段即止。
