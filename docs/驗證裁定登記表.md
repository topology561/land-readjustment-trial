### 四、🔴🔴 **本裁之主要產出：那個「衝突」不存在**

🔒 **該衝突⛔ 不存在。** 理由一行：**`X` 恆在<u>線 `j`</u> 上。**

設 `X = p_j + s*·û_j`（`s* = d_signed / sinα`·**已是現行構造量**）。街廓（凸）＝ 各邊外向半平面之交
⇒ `X ∈ block` ⟺ 對每一邊 `e`（外向法向 `n_e`、邊上一點 `q_e`）皆有 `⟨X − q_e, n_e⟩ ≤ 0`
⟺ **`s*·⟨û_j, n_e⟩ ≤ ⟨q_e − p_j, n_e⟩`** ——**每一邊給 `s*` 一個一維界**。取交集：

> 🔑 **在內 ⟺ `s* ∈ [λ_a, λ_b]`**，其中
> `λ_b = min{ ⟨q_e−p_j, n_e⟩ / ⟨û_j, n_e⟩ : ⟨û_j, n_e⟩ > 0 }`
> `λ_a = max{ ⟨q_e−p_j, n_e⟩ / ⟨û_j, n_e⟩ : ⟨û_j, n_e⟩ < 0 }`

**其性質（逐項）**：
1. ⛔ **不需算 `X`**——只需 `p_j`／`û_j`／街廓頂點，全部為構造量；`s*` 本已在白名單內。
2. ⛔ **不需 `contains()`／`intersection()`**——純算術（此即 Cyrus–Beck／Liang–Barsky 線裁剪）。
3. 🔒 **每個街角宗只算一次** `[λ_a, λ_b]`；其後**每一對 `k` 只是一次純量比較** ⇒ 計算量由 `O(對數)` 降為 `O(街角宗數)`。
4. 🔒 **它是恆等式、⛔ 非近似**——對凸街廓精確；非凸者化為**區間之聯集**（本案已判皆凸 ⇒ 單區間）。

🔑 **⇒ 現行外接盒式之病因已完全清楚**：
**外接盒 ＝ 同一演算法，只是拿了 4 條<u>錯的邊</u>（`s`／`t` 軸向）去裁，而街廓有 5〜9 條<u>對的邊</u>。**
