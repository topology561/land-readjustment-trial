## 一、記號（沿用 `k97_solve_alloc_t` 現行框，⛔ 不另立）

`grep -n "def k97_solve_alloc_t" app.py` 之函式內：

| 符號 | 意義 |
|---|---|
| `F1`、`d̂` | 前緣線起點與單位方向 |
| `b̂n` | BASELINE 法向（已定號**指向 BASELINE**）|
| `ân`、`an` | ALLOC 方向之法向 |
| `t` | ALLOC_LINE 之平移參數 |
| `c0` | `(Q0 − F1)·ân` |
| `den_a` | `d̂·ân` |

**ALLOC_LINE 之集合式（本推導之樞紐）**：

```
L_in(t) = { X : (X − F1)·ân = t + c0 }
```

驗證：`X = F1 + s·d̂ + d·b̂n` ⇒ `(X−F1)·ân = s·den_a + d·(b̂n·ân)`，
令其 `= t + c0` 得 `s = (t + c0 − d·(b̂n·ân)) / den_a`，
與碼面 `_s_alloc(d, t)`（`grep -n "def _s_alloc" app.py`）**逐字相同** ⇒ 框一致。

## 二、🔑 切換點之閉式（**一次減法·無迭代**）

第二層分支之界 ＝ **`P_block` 通過街廓多邊形某個頂點之 `t`**。
由 §一 之集合式，對**任一頂點 `C`**：

```
t_C = (C − F1)·ân − c0
```

⇒ **切換點不需要解方程、更不需要搜尋**：把街廓多邊形的頂點逐個代入即得。

### 由此得到比「2×2×2」更乾淨的結構

施工單述為 `2×2×2 = 8` 支（`k` 之正負 × `m·t` 之正負 × `P_block` 落截角邊/FRONT 重疊段）。
本推導指出：**第三個維度其實是「`P_block` 落在街廓邊界的哪一條邊」**，而非只有兩種。
對每條邊 `E_i = [C_a, C_b]`：

- 其對應之 **`t` 有效區間** ＝ `[min(t_Ca, t_Cb), max(t_Ca, t_Cb)]`（由上式直接得）；
- 在該區間內，`P_block(t)` **沿該邊線性移動**：
  設邊之單位方向 `ĉu`，則
  ```
  P_block(t) = C_a + λ(t)·ĉu ,   λ(t) = (t − t_Ca) / (ĉu·ân)
  ```
  （`ĉu·ân = 0` ⇒ 該邊平行 ALLOC ⇒ **無單點交** ⇒ 該邊不產生分支·loud raise 不適用，直接跳過）

⇒ 本案街角附近之邊恰為**截角邊**與 **FRONT 重疊段**二條 ⇒ 退化回施工單所述之 2 支；
但**實作採逐邊通式**，故換案（多段截角、圓弧近似為折線）時**不需改結構**。
🔒 這也同時滿足 §六 之停機條件「第二層分支需要二分或取樣才能定位 ⇒ 停機」——**本式不需要**。

## 三、深度項之改寫（K-9-8 (5)：深度自 `PQ` 起算）

現行式之 `D(t)` 係「臨街段 `Q0 → P_front(t)` 各點至 BASELINE 垂距之 min」，
其中臨街段落在 **FRONT_LINE** 上 ⇒ `D(t) = D0 − m·t`（`m = g/den_a`，`g = d̂·b̂n`）。

K-9-8 改為：臨街段落在 **`PQ`** 上——`PQ` ＝ 過 `P_block(t)`、**平行前緣線**之直線，
其二端為 `P_block(t)` 與 `PQ ∩ SIDE_LINE`。因 `PQ ∥ FRONT`：

```
D_new(t) = min( dep(P_block(t)) , dep(PQ(t) ∩ SIDE_LINE) )
```

且 `dep(·)` 沿 `PQ` **線性**（BASELINE 為直線）⇒ **取兩端即得 min**、⛔ 不取樣。

### 兩支之形

- **`P_block` 落 FRONT 重疊段**：`P_block(t) = P_front(t)` ⇒ `PQ ≡ FRONT`
  ⇒ **`D_new(t) ≡ D(t) = D0 − m·t`**（＝ K-9-8 (6) 之退化·**與現行同**）。
- **`P_block` 落截角邊**：代入 §二 之 `P_block(t) = C_a + λ(t)·ĉu`（λ 線性於 `t`）
  ⇒ `dep(P_block(t))` **線性於 `t`** ⇒ `D_new(t) = D0' − m'·t`，
  其中 `m'` 由 `ĉu` 與 `b̂n` 決定，**閉式**：
  ```
  dep(P_block(t)) = dep(C_a) − (ĉu·b̂n)/(ĉu·ân) · (t − t_Ca)
  ```
  （符號依 `b̂n` 之既有定號）。

⇒ **每支仍是一次式** ⇒ `W(t) = w₀' + (c − k·m')·t` ⇒ **每支一次除法**，與現行四支同型。

## 四、八支之列舉（`k` 正負 × `m'·t` 正負 × 落邊）

| # | `k` | 深度支 | `P_block` 落 | 斜率 | 有效區間 |
|---|---|---|---|---|---|
| 1 | `≥0` | — | FRONT 段 | `c` | `t ∈ I_front` |
| 2 | `≥0` | — | 截角邊 | `c` | `t ∈ I_cham` |
| 3 | `<0` | `D` 常數 | FRONT 段 | `c` | `m·t ≤ 0` ∧ `t ∈ I_front` |
| 4 | `<0` | `D` 常數 | 截角邊 | `c` | `m'·t ≤ 0` ∧ `t ∈ I_cham` |
| 5 | `<0` | `D(t)` 遞減 | FRONT 段 | `c − k·m` | `m·t > 0` ∧ `t ∈ I_front` |
| 6 | `<0` | `D(t)` 遞減 | 截角邊 | `c − k·m'` | `m'·t > 0` ∧ `t ∈ I_cham` |
| 7 | `<0` | 切換點 | — | — | `m'·t = 0`（②↔③ 之界·現行已列）|
| 8 | — | 落邊切換 | — | — | **`t = t_C`（本推導新增之界）** |

`k ≥ 0` 時深度不影響 ⇒ 1／2 兩支；`k < 0` 時再分深度支 ⇒ 3–6。
7／8 為**界**而非解支（列出以滿足「切換點須明列」）。

⛔ **退化一律 loud raise**：`ĉu·ân = 0`（邊平行 ALLOC）／`c − k·m' = 0`（斜率退化）／
無任何支之 `t*` 落在其有效區間 ⇒ 停機，**禁兜底**。
