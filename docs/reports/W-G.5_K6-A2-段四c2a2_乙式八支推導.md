## 二、🔴 `δ_P(t)` 之定義與閉式——**⛔ 不是 `(P_block − F1)·b̂n`**

### 2-1 定義

`δ_P` ＝ 使 **`PQ ＝ FRONT_LINE 沿 `b̂n` 平移 δ_P`** 成立之平移量。
即：在 `{d̂, b̂n}` 這組（**非正交**）基底下，把 `P_block − F1` 拆成

```
P_block − F1 = α·d̂ + δ_P·b̂n
```

之 **`b̂n` 分量**。（`PQ` 過 `P_block` 且 `PQ ∥ FRONT` ⇒ `PQ = {F1 + δ_P·b̂n + s·d̂}` ✓）

### 2-2 閉式（以 FRONT 之單位法向 `n̂` 取分量）

令 `n̂ = (−d̂_y, d̂_x)`（⊥ `d̂`）、`h = b̂n·n̂`、`g = d̂·b̂n`（`g² + h² = 1`）：

```
(P_block − F1)·n̂ = α·(d̂·n̂) + δ_P·(b̂n·n̂) = 0 + δ_P·h
⇒  δ_P = ((P_block − F1)·n̂) / h
```

⛔ **`h = 0`（`b̂n ∥ d̂`⇔ BASELINE ⊥ FRONT）⇒ `PQ` 不可由 `b̂n` 平移表出 ⇒ loud raise。**

### 2-3 🔴 為何**不能**寫成 `(P_block − F1)·b̂n`（施工單 §二-2 之字面式）

```
(P_block − F1)·b̂n = α·(d̂·b̂n) + δ_P·(b̂n·b̂n) = δ_P + α·g
```

⇒ 二式差 **`α·g`**，`α` ＝ `P_block` 沿 `d̂` 之座標（可達街廓全長）。
**僅當 `g = 0`（FRONT ∥ BASELINE）二者才相等**——本案六街廓**皆非**。

**實測（`bf6c13f`·16 格·⛔ 非估算）**
——⚠️ 本表量於**甲式之 `t*`**（本文尚未落地時之狀態）；
本表旨在證**二式之結構差**（`α·g`），**與取哪一個 `t*` 無關**
⇒ 乙式落地後 `δ_P` 之值會微動（例 `R3/right 0m`：`0.059883 → 0.064305`），
**但結論（字面式錯 1〜4 公尺）不變**：

| 格 | `g` | `α` | **`δ_P`（本文式）** | `(P_block−F1)·b̂n`（字面式） | 差 ≈ `α·g` |
|---|---:|---:|---:|---:|---:|
| **R6/right 0m** | +0.050035 | 82.3549 | **0.000006** | **4.120598** | **+4.12 m** |
| **R3/right 0m** | −0.012057 | 89.8996 | **0.059883** | **−1.024066** | −1.08 m |
| R5/left 3.5m | −0.047345 | 10.2898 | −0.000000 | −0.487173 | −0.49 m |
| R2/left 3.5m | +0.009726 | 10.3885 | 0.000003 | 0.101039 | +0.10 m |
| R1/left 0m | +0.000409 | 3.5134 | 0.166151 | 0.167587 | +0.0014 m |

⇒ 字面式最劣**錯 4.12 公尺**（`R6/right`），⛔ 不可用。

🔒 **三條旁證，指向本文式即裁定本意**：
1. **施工單自身之 §三 階段 A 預測表**以 `k · δ_P` 估殘差，其 `δ_P` 取自
   `probe_K9_7d_layer2`【C】段之**內縮欄**（`R3/right 0m` ＝ `0.059879`、
   `R1/left 0m` ＝ `0.166151`）——**與本文式逐格相符**（差 `1/|h|`，本案 `|h| ≥ 0.9987`），
   **與字面式相差 1〜4 公尺**。
2. 內縮欄之定義為 `|(P_block − F1)·n̂|`（`grep -n "_t_front = abs" app.py`），
   即 **`|δ_P·h|`** ⇒ 與本文式同源、只差 `|h|`；而 `|h| ≈ 1` 正是本案數字對得上的原因。
3. 若採字面式，`R6/right` 之帶將被推離 4 公尺 ⇒ 其寬度必翻爛，
   而該格為 `k ≈ 4.8e-08`（近乎不受深度影響）之對照組 ⇒ **必生假紅**。

⇒ 判為施工單之**筆誤**（純技術·非域裁），本批依 2-2 之閉式實作並於報告載明。

### 2-4 逐邊仿射（＝ 每支仍一次式之關鍵）

於邊 `E_i = [C_a, C_b]`（`ĉu` ＝ 單位方向、`e = ĉu·ân ≠ 0`）：
`P_block(t) = C_a + λ(t)·ĉu`、`λ(t) = (t − t_Ca)/e`（沿用甲式 §二·未變）

```
δ_P(t) = [ (C_a − F1)·n̂ + λ(t)·(ĉu·n̂) ] / h  =  A_δ + B_δ·t

  A_δ = [ (C_a − F1)·n̂ − (ĉu·n̂)·t_Ca/e ] / h
  B_δ = (ĉu·n̂) / (e·h)
```

**⇒ `δ_P(t)` 於每條邊上為 `t` 之仿射函式。**

## 三、乙式之 `W(t)`

`w(d, t) = w₀ + c·t + k·d`（未變）。帶之二端為 `d = δ_P(t)` 與 `d = δ_P(t) + D_new(t)`：

```
W(t) = min( w(δ_P(t), t) , w(δ_P(t)+D_new(t), t) )
     = w₀ + c·t + k·δ_P(t) + min(0, k·D_new(t))
```

`D_new(t) > 0`（否則 loud raise）⇒ **`min` 之取捨只由 `k` 之正負定**：

| `k` | 最小寬取在 | `W(t)` |
|---|---|---|
| `k ≥ 0` | 帶之**上緣**（`d = δ_P`） | `w₀ + c·t + k·δ_P(t)` |
| `k < 0` | 帶之**下緣**（`d = δ_P + D_new`） | `w₀ + c·t + k·(δ_P(t) + D_new(t))` |

代入 §二-4 與甲式之 `D_new(t) = A + B·t`（逐邊·逐深度端支·未變）：

```
k ≥ 0 :  W(t) = (w₀ + k·A_δ)       + (c + k·B_δ)·t
k < 0 :  W(t) = (w₀ + k·(A_δ + A)) + (c + k·(B_δ + B))·t
```

**⇒ 每支仍為 `t` 之一次式 ⇒ `W(t*) = T` **每支一次除法**。**
⛔ 禁二分、禁取樣、禁迭代兜底。

## 五、🔴 結構後果：**分支 ① 失去「與邊無關」之性質**

**甲式**：`k ≥ 0` ⇒ 最小寬取在帶之上緣、而上緣**固定為 FRONT** ⇒ `W = w₀ + c·t`
⇒ 與 `P_block` 落哪一條邊**無關** ⇒ 可於逐邊迴圈**之外**一次解畢。

**乙式**：上緣改為 `PQ(t)` ⇒ `W = w₀ + c·t + k·δ_P(t)`，
而 `δ_P(t)` **於每條邊上各有一條仿射式**
⇒ **分支 ① 必須併入逐邊通式求解，其解亦須落在該邊之 `t` 有效區間內才成立。**

⛔ **若保留一條錨在 FRONT 之「① 快捷路徑」**，本案
**`R1/left 0m`（邊 4）** 與 **`R3/right 0m`（邊 1）** 將算錯
——而這兩格正是本裁定影響**最大**與**次大**之格。

## 六、與甲式之差（＝ §三 階段 A 之預測式）

同一 `t`，乙式之 `W` 較甲式多 **`k·δ_P(t)`**（帶之二端一齊平移 `δ_P`，`min` 之取捨不變）。
⇒ 以**甲式夾具**量**乙式引擎**所定之 `t*`，其殘差為

```
殘差 = W_甲(t*_乙) − T = −k·δ_P(t*_乙)
```

（引擎已令 `W_乙(t*_乙) = T`。）⇒ **量級 ＝ `|k·δ_P|`、符號與 `k·δ_P` 相反。**
🔴 此處之 `k` 須取**解析 `∂w/∂d`**，⛔ **不得取正典 K-9-7-c 表之 `k` 欄**
（該欄係擾動觀測 `∂W/∂D`、於 `k ≥ 0` 時恆觀測為 `0`·該表下方警語逐字「禁當解析靶」）。

## 七、🛑 停機條件之檢查結果

施工單 §一 之停機條件：「若推導後任一支**不是一次式**（例如 `δ_P(t)` 與 `D_new(t)` 之端點
選擇互相耦合出二次項）⇒ 停機上呈」。

**未觸發**：`δ_P(t)` 與 `D_new(t)` **各自**於同一條邊上為仿射，且二者**相加**進入 `w(d,t)`
之 `d`（`w` 對 `d` 為一次）⇒ 合成仍為一次。端點選擇（`dep_P` vs `dep_Q`）只切換
**用哪一條仿射式**，不產生乘積項。⇒ **每支一次除法之結構完好。**
