## 三、失敗考古：**空真型假綠**（建議入節 53）

**症狀**：`不符 == 0` ⇒ 印 ✅。
**根因**：`0` 有兩種來源——「**檢查過而全對**」與「**根本沒有可檢查者**」；
`==0` 之判式對二者**全盲**。
**通則**：凡「不符數／失敗數 == 0 ⇒ ✅」之判式，**必須同時斷言母體 > 0**；
母體為 0 時應印 🔴「未經證明」而**非** ✅。
**與既有之別**：`CLAUDE.md`「計數為 0 而結論為『無變化』」講**受測方未被咬到**；
本例是**對照方不存在**。二者皆為「0 最該懷疑」，但**要加的斷言不同**
（前者加「咬到計數」，後者加「**母體計數**」）。
