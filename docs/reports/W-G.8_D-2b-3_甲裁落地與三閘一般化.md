## 二、§二 三閘合圍一般化（**已落地**）

### 2-1 恆等式與**唯一產生器**

```
ΣRw_側 == [R(W_final) − R(W₀)] − Σ_i Δ_i        Δ_i ≡ R(W_near,{i+1}) − R(W_far,i)
```

推導：每宗 `Rw_i = R(W_far,i) − R(W_near,i)` ⇒ 望遠鏡和展開即得。
🔒 **鏈連續時 `Δ_i ≡ 0`、退化為原式** ⇒ ⛔ 未放寬 `0.1`、⛔ 未刪閘、⛔ 未整側豁免
（僅把「鏈斷」由**隱式失敗**改為**顯式帳目**）。

**產生器恰一處**（§二-5）：`grep -n "def _iface_deltas" verify/stepg_pipeline.py` ⇒ `:1067`
（全倉命中 **1**）。配套 `_chain`:1044／`_dir_is_alloc`:1033／`_guard_auth_scope`:1100。
三閘皆呼叫之（§二-4）。

### 2-2 授權判準 **data-driven**·且**非套套邏輯**

判準＝「該宗遠側界方向 ≠ 街廓 ALLOC 方向」（`_dir_is_alloc`·`|cross|≤1e-6`）
——⛔ 未用街廓名／側別字串／宗序號。

🔑 **為此在 `app.py` 加了一欄**（**具名偏離施工單「不觸生產碼」·⛔ 不默默做**）：
`_solve_G_one` 於決定點後記錄 `res['_alloc_dir_used']`（**純加性**·⛔ 零行為變更·⛔ 無消費者
讀之以改行為）。**理由**：若方向由 harness 依 `is_corner` **自行重算**，則
「判準集合 == 標記集合」淪為**套套邏輯**（`fixture-provenance`：期望值不得由受測邏輯自產），
§二-3 之斷言將永真而不咬。⇒ 方向須由**生產路徑本身**輸出。
該處為 **module 級**（`:11517` < `main()`:12453）⇒ 可 harvest、**不需合成案**。
