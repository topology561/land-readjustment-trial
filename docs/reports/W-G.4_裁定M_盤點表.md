## 〇、最重要發現：M-2 直擊「9 戶差 2 戶」之成因鏈（**倉內既有 baseline ＋ 探針雙向印證**）

倉內 `verify/baselines/第 1 宗街角地指配結果_退縮3.5m.csv` 與本波容量拆解探針
（`verify/out/probe_capacity_decomp.log`）**逐位吻合**：

| 端 | 3.5m 第1宗指配（baseline） | 最小面積 | 探針測 forced 鎖定 | |
|---|---|---|---|---|
| R5 左 | ⚠️ **強制抵費地** | 300.52 | **300.52** | ✅ 逐位同 |
| R2 左 | ⚠️ **強制抵費地** | 309.05 | **309.05** | ✅ 逐位同 |
| R3 右 | ⚠️ **強制抵費地** | 308.93 | **308.93** | ✅ 逐位同 |
| | | **Σ 918.50** | **Σ 918.50** | |

**0m 對照**：三端**皆有地主宗入選**（R5左 G005／R2左 G023／R3右 G007）⇒ 無強制抵費地
⇒ 探針測 forced 鎖定**全 0** ⇒ 0m E2 可行。

**成因鏈（六節·全由倉內物證串起）**：

```
3.5m 退縮 → range(T=退縮+法定最小寬) 變大 → 街角規定面積 225~309㎡
  → 三端候選 G_est 全 < 門檻 → _pk_one_side_v12 全數 eliminated
  → 第1宗 = ⚠️強制抵費地（app:15062 `'強制抵費地' in 【左/右】第1宗指配`）
  → left/right_forced_offset=True、corner_min_area=range 面積
  → _classify_fragments 判「forced角落鎖定」→ _s0_unreachable 計入不可達
  → reachable −918.50㎡ → E2 容量不足 → 9 戶落不下 2 戶
```

⇒ **M-2 之上位精神（「能以地主土地填滿街角規定面積即不用抵費地」）正是此鏈之解**：
若合併自救使三端任一取得地主宗 winner，該端 forced 鎖定即**不生**、range 面積釋回可分配。
**本波首要驗收讀數（9戶差2戶是否消失）與 M-2 直接同源**——非兩件事。

### 2.1 ⚠️ 潛在衝突：E-1.7 空間濾網

`corner-selection-rules` 載資格為**雙條件**：**E-1.7 空間濾網（真交集 > 1.0㎡ 絕對地板）
＋ G估 ≥ 門檻**。M-2 只言 G 門檻之自救，**未言空間濾網是否隨之放寬**。

- 合併係**面積（a′）**合併，**不改變**該宗與街角範圍之**真交集幾何**。
- ⇒ 若某宗真交集 <1.0㎡（幾乎不跨占街角），縱合併後 G 夠大，**仍不宜**當街角地。
- **CC 判讀**：M-2 僅改 G 門檻這關，**E-1.7 空間濾網應保留**（且 M-2 文字本身即限定
  「**跨占**街角規定範圍地」＝已隱含跨占要件）。→ **列 plan 明示、不自行放寬**（見 §五 Q2）。
