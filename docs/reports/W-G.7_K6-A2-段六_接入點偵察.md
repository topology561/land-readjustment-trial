## 二、7-2 受測對象辨明：**兩個多邊形、兩條起算線、兩個帶**

### 2-1 後置斷言所保證者 ＝ **構造出來的尺**（不是實配的地）

`app.py:10225`〜`:10231`（`k97_solve_alloc_t` 內·**K-9-5-2 ③ 之程式化**）：

```
_D_at = D0 - max(0.0, m * t_star)
_W_at = min(_W(0.0, t_star), _W(_D_at, t_star))
if not (_W_at >= T - 1e-6):
    _stop("後置斷言破：所構造範圍之最小寬 … < 退縮＋畸零地最小寬 …")
```

🔑 其受測者為 **`t*` 所參數化之範圍**——而 `t*` **正是被解出來使該範圍之最小寬等於 `T`** 者。
⇒ **該斷言為「構造之自檢」，恆真乃設計使然**；它保證的是**尺本身有 `T` 這麼寬**，
⛔ **不保證**「實際配給 winner 的那塊地有 `T` 這麼寬」。

### 2-2 兩個多邊形之逐字對照
