### 2-3 🛑 與授權第 3 條之衝突（此為停機之真正理由）

授權第 3 條逐字（`K-6:930`–`:931`）：

```
3. 重烤範圍**限於因 D-1/D-2/D-2b 之分配變更而過期者**；
   ⛔ 不得順手重烤其他錨、⛔ 不得擴及未受本波影響之名目。
```

那 **7 檔**（指配 2＋診斷 4＋抵費地 1）**正是**「因具名之 `D-1`／`D-2`／`D-2b` 變更而過期者」
⇒ **第 3 條把它們納入範圍，護欄要把它們排除。**

⇒ 護欄**不是第 3 條之「具體化」，而是對第 3 條之<u>例外／優先序</u>**——
即「**縱使過期，仍不重烤，因非同源之不可逆性優先於錨值之新鮮度**」。
**二者法律結構不同**：前者是解釋，後者是新規範。
⛔ 我不能把假的事實陳述寫進正典，亦不得逕自把「具體化」改寫為「例外」——**該擇一屬域裁。**
