## §六　🔒 環境與陷阱（⛔ 本窗**實際踩過**者·⛔ 非泛論）

1. **`cp950`**：印中文之 Python 一律 `PYTHONIOENCODING=utf-8`（見 §二-2）。
2. **量測框**：工作樹為 **CRLF**、blob 為 **LF** ⇒ **校驗碼／位元組數一律先聲明量測框**；
   比對前 `CRLF → LF`（`wg942_append_audit` 早有此範例·⛔ 有現成的就照抄）。
3. 🔴 **`grep` 之多位元組陷阱（本窗踩過二次）**：
   · `[^」]` 等**否定字元類含 CJK** ⇒ 逐位元組解讀 ⇒ **靜默漏數**（實測 165 → 38）；
   · `grep -c $'\r'` 於**純 LF 檔**回傳「行數」而非 0。
   ⇒ **計數一律以 Python `re` 或 `od` 對帳；兩數不一致時⛔ 不得取其一逕行出艙。**
4. 🔴 **`echo` 內含反引號會被 shell 展開**——本窗曾因此**憑空建出三個 0-byte 垃圾檔**，
   而我當時只查了目標檔就寫下「未造成任何檔案變更」。
   ⇒ 🔒 **宣稱「沒造成變更」前一律跑 `git status --porcelain`（<u>全樹</u>）。**
5. 🔴 **以 patch 腳本改碼會寫進真的控制字元**——`'\\b'` 於非 raw 字串成為**退格 `0x08`**，
   寫入正則後該式**永不匹配**，而 `py_compile` **照過**。
   ⇒ 🔒 **凡以腳本生成／改寫正則，一律 `cat -A` 或 `repr()` 複驗。**
   ⇒ 🔒 **改多行 CJK 檔時，優先用 Write／Edit，⛔ 少用 `sed`**（本窗曾以 `sed` 截斷多位元組）。
6. **長跑期間⛔ 不得動 `app.py` 與 `verify/` 下任何檔**（`CLAUDE.md`）——
   `run_all` 約 10 分鐘，背景跑 ＋ 等通知。
7. **改回傳元組之形狀時**，受影響處**⛔ 不是「我記得的那幾處」，是 `grep` 出來的全部**
   （本窗因此炸過兩次）。
8. **`verify/out/` ⛔ 禁 `git add -A`／`.`**——一律逐檔 `git add`；commit 前對照異動清單。
9. **巢狀 worktree 污染 grep**：`.claude/worktrees/` 為完整倉庫副本、`git status` 看不到但
   `grep -rn … .` 看得到 ⇒ **證據指令一律正面列舉受檢檔**。（本 worktree 內**無**巢狀·已現查。）

## §七　🔒 方法論結晶（本窗之骨幹·⛔ 下一批直接可用）

### 量測器七戒

1. **對照組只能在<u>受詞那個維度</u>上不同**——取一個「全 0」之字當對照，證明不了任何事。
2. **大得離譜的數，第一嫌疑是量測器**（實測：以單式量定義列得「86 中 74 懸空」⇒ 真為 **2**）。
3. **「明細內」與「全檔」是兩個分母**——同一個 grep，母體不同就是不同的數。
4. **量測器之修正必須<u>遞迴</u>施用**——離譜的數字會自己求救，**合理的不會**（殘數 2 ⇒ 真為 0）。
5. **每一張判定表都要有「預期」欄**——沒有它，極性錯了看起來只像「一個有點意外的結果」。
6. **`PASS` 是三義詞**：「檢過了」／「檢跑了但**沒東西可檢**（0 列）」／「檢**根本沒跑**」。
7. **`py_compile` 過 ⛔ 不等於字串內容是你以為的那個**（見 §六-5）。

### 🩸 錯誤方向決定它會不會被抓到（考古**節 98**·本窗立）

> **偵測器往「多報」錯會吵、會被追；往「少報」錯會<u>安靜</u>，而安靜正是它要對抗的東西。**

**本窗之雙實證**：
· **前綴碰撞**（`GB-8` 匹配到 `## \`GB-81\``）⇒ 只讓懸空**變小** ⇒ **假綠·安靜** ⇒ 靠他方複算才抓到；
· **極性反轉**（`<` 式之真值當成轉紅）⇒ **自相矛盾·很吵** ⇒ **一次就抓到**。
🔒 **推論**：寫「找漏」之工具**前**，先問「**我漏掉東西時往哪個方向錯？**」並**寫進 docstring**。

**正好包含本批唯一量到「佔用」的那一筆**。

### 其他四則

* **停機須掛在「<u>本塊自身所斷言</u>之命題」上**——以摘述之數停一個它沒斷言的命題，即是重演該錯。
* **「機制之盲」與「盲域之佔用」是兩個問題**（節 99）——閘為盲 ≠ 盲域裡此刻有東西。
* **相等比較之盲域 ＝ ∅** ⇒ 「容差 vs 粒度」之問對其**不適用**
  ⇒ 🔒 **`GB-27` 並不代表正典所指之三族**（10 處比對點中 **8 處**為相等式）。
* **動一個共用判準之前，先讀它自己的檔頭**——那裡通常寫著誰封的、為什麼封。
