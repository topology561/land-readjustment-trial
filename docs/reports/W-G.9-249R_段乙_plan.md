### `a`　新增 module 級純函式（**⛔ 動任何既有函式一字**）

| 符號 | 職責 |
|---|---|
| `k6b_stage3_trial(...)` | 段三 `1`–`5` 之**過程**；**純函式·唯讀·⛔ 寫回任何 session／候選物件** |

**入參**（全部取自既有產出·⛔ 重算）
`stage2_order`（`f3_k6b_stage2_order`）／`locked_by_block`（`f3_k6b_stage1_locked_by_block`）／
`merge_groups`（以全案 `temp_parcels` ＋ `own_map` 呼叫 `k6_merge_groups` 所得）／
`temp_parcels`／`cand_by_pid`（含 `min_area_to_apply`／`_corner_intersection_area`）／
`recompute_G`（**callable**·由呼叫端以 `_corner_block_true_G` 之閉包注入 ⇒ 本函式⛔ 綁街廓級參數）。

**演算法**（逐款對正典）

```
for 每一「待處理街角」(街廓, 端)：              # 段一判全部未達者 ＝ stage2 之母體
  for 候選 in stage2_order 中該街角之列（依 最終序位 升冪）：   # 款 1・I-4
    g  = 該候選所屬之合併群（merge_groups 查得）              # 款 1・I-2
    ms = g 中「未上鎖」之其他片                                # 款 1・I-3
    if 群為空 或 群中無「有跨占街角」之片：
        判 = 不可算（具名成因）；continue                     # 單 §三 逐字・⛔ 當失敗⛔ 當成功
    if 群中有一片已達其所在街角規定面積：
        判 = 不可算（落款 2 第二分支・本批⛔ 及）；continue
    標的 = ms ∪ {候選} 中「有跨占街角 ∧ G 最大」之片          # 款 2 第一分支
    a'   = Σ(群中各片之 a)        # RD 片整筆併入（I-6：併面積・⛔ 立宗・⛔ 佔位次）
    G'   = recompute_G(標的, a')                              # 款 3
    判   = 成功 if G' >= 門檻 else 失敗                        # 款 4（裁乙：先達標者即 winner）
    if 成功：記為該街角之 winner（**觀測**）；break            # 每候選只試一次
    else   ：還原（款 5）；continue
  else：該街角維持段三-6（強制抵費地・現行行為）
```

🔒 **裁乙之逐字入碼註**（單 `§二 c`·⛔ 省）：依段二之序逐一嘗試，**先達標者即為 winner，
⛔ 再與其他候選比街角指數**；其由 ＝ 段三標題「每候選只試一次」＋ 段二鍵序本即「輪到誰試」之定序。
