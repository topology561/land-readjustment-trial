## 八、🔴 本批自查出之三處探針缺陷（**併記·⛔ 不隱藏·首版已修**）

首版探針（未入倉）產出後自查，發現三處**若照發即為假結論**：

1. **萬用桶**：缺口 100% 落入「（宗內／池帶）」單一桶 ⇒ **是改標籤、不是分解**，
   殘差之所以為 0 係萬用桶吸收所致。違 `D-2b-10`「去萬用桶」。
   → 改為 **s 軸初等分段**（無「其他」桶；落不進具名者一律 `🔴 未歸戶`）。
2. **命名法不同卻並列比較**：§2-2 乙法按 s 歸單桶、甲法按**對**命名 ⇒ Δ 欄出現 `−76.27`／`+46.05`，
   外觀像「兩法嚴重不合」，**實為命名法錯配**。→ 乙法改**逐對**計數，與甲同義。
3. **套套邏輯**：§2-3 夾角原以「跑兩情境都同值」宣稱其不隨情境變，
   而 `build_pipeline` 在情境迴圈**外**只跑一次 ⇒ 讀的是同一物件、**必然**同值。
   → 改為**可失敗斷言**（每情境 `build_param_table` 後重讀比對·結果漂移 **0** 筆）。

🔒 **通則**：本三者外觀皆為「✅ 綠、殘差 0」。**殘差為 0 不等於分解成立**——
須另問「**分項是否具名**」與「**該比較是否具鑑別力**」。
