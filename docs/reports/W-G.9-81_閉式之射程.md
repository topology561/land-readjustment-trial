### 🩸 I-2　第七法之首版**經 shell 傳遞含反斜線之碼** ⇒ `SyntaxError`

**錯**：以 `python -c "...elif c=='\\\\': ..."` 傳遞狀態機之碼 ⇒ bash 吃掉反斜線 ⇒
`elif c=='\':` ⇒ **`SyntaxError: unterminated string literal`**。
🔴 **要害**：`W-G.9-80` §I-2 之修法**是我自己寫的**（「凡樣式含反引號／反斜線，⛔ 不得經 shell」），

🔒 **它當場 `SyntaxError` 是運氣，⛔ 不是修法生效**（若少一個反斜線可能靜默跑出錯的數）。
🔒 **修法擴充（自用）**：**凡經 shell 傳遞之 Python 碼，一律 `python - <<'PYEOF'`（quoted heredoc）**
——⛔ 不論其內容看起來有沒有反斜線。
