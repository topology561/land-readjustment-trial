## §六　🔒 環境與陷阱（⛔ 本波實際踩過者·⛔ 非泛論）

1. **heredoc**：`bash` 對含大量中文之 `<<'EOF'` **會誤解**（本波兩度 `unexpected EOF`）
   ⇒ 🔒 **改為先把 `.py` 寫進 scratchpad 再執行**。
2. **`subprocess` 之 `text=True`** 以 `cp950` 解碼 ⇒ 命中行含中文即 `UnicodeDecodeError`
   ⇒ 🔒 顯式 `.decode("utf-8")`。
3. **中文路徑之 `git`**：`--stat` 會八進位跳脫 ⇒ 一律 `-c core.quotePath=false`。
4. **`verify/out/`**：⛔ **禁 `git add -A`／`.`**——該目錄混放入庫證據與本機臨時 log，
   一律**逐檔 `git add`**，且 commit 前跑 `git diff --cached --name-status` 對照。
5. **長跑期間 ⛔ 不得動 `app.py` 與 `verify/` 下任何檔**（會污染受測靶且**不報錯**）。
6. **探針之 module 級開關**（`probe_WG949.LOCAL_ORIGIN`／`probe_WG962.INJECT`）
   ⇒ 一律 `try/finally` 還原，**且於探針結束時以斷言驗其已還原**。
