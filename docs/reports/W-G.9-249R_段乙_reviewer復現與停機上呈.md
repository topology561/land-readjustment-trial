```
app.py:14038-14041

  pre_p  = float(pre_price_by_zone.get(zone, 0.0) or 0.0)
  A_ratio = ((post_price_blk / pre_p) if (pre_p > 0 and post_price_blk > 0) else 1.0)
```

`A_ratio` **只取標的 `pid` 一個「重劃前地價區段」**，而段三之 `a′ ＝ Σ(群中各片之 a)` 係

🛑 **此屬「附件二公式選擇／法規本意」層** ⇒ **⛔ 由 CC 或同模型 reviewer 拍板**，交 KL＋發單側。
