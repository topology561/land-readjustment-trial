## 五、§五-3：(a) 之量法與自檢①′ **同源之對讀**

**自檢①′**（`app.py`·`grep -n "自檢①′" app.py`）：

**本檔**（`probe_K9_s62_k98_line_vs_chord.py`·`_s_on()`）：

```python
def _s_on(pA, pB, _T):
    """過 `pA`、`pB` 之**無限直線**於深度 `_T` 之 `s`（⛔ 解析·非 GEOS）。"""
    _a, _b = _to_st(pA), _to_st(pB)
    if abs(_b[1] - _a[1]) < 1e-12:
        return float('nan')
    return _a[0] + (_T - _a[1]) / (_b[1] - _a[1]) * (_b[0] - _a[0])
_ld = abs(_s_on(_lin[0], _lin[1], _t) - _s_on(sd["p1"], sd["p2"], _t))
```

**對讀**：二者**同一幾何量**——「該深度之量測線與**二側無限直線**之交點，沿 `d̂` 之座標差」。
🔴 **差別（須明載·⛔ 非同一實作）**：

| | 自檢①′ | 本檔 |
|---|---|---|
| ALLOC 線之來源 | **構造解 `t*`** | **winner 實配之 `L_in`**（＝本檔之受測對象） |
| 求交路徑 | GEOS 世界座標（`_LBIG` 無限線段） | **`(s,t)` 局部框解析**（**E-10**·見 §一-1-1 之錯 2） |

⇒ **量的是同一種量、以不同精度路徑求**；本檔之路徑係因 **E-10** 而**必須**改的
（GEOS 於共線情形回錯值，已由自我驗證閘實證）。
