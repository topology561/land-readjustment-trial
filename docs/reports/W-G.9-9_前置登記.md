## §1 投影之定義（⛔ **逐字寫死**·施工單 §5·§6 閘 1 須與實作逐字相符）

**函式**：`_project(lines) -> list[str]`，置於 `verify/fixture_e2e_termination.py`。

```
FRAME = ^\s+File "(?P<f>[^"]*)", line (?P<n>\d+), in (?P<fn>.*)$

def _project(lines):
    frames = [i for i, l in enumerate(lines) if FRAME.match(l)]
    if frames:
        i = frames[-1]                       # 最後一幀 ＝ raise 點
        head = [lines[i].strip()]
        tail = lines[i + 1:]
    else:
        head = ["(無 traceback 幀)"]         # ⛔ loud·非靜默 fallback
        tail = lines
    exc = []                                  # 自末端往回取「連續之無縮排行」
    for l in reversed(tail):
        if (not l.strip()) or l[:1].isspace():
            break
        exc.insert(0, l.rstrip())
    return head + exc
```

- **正規化**：`R1`／`R2`（`wv_reconcile.normalize`）**照舊**套用於投影**後**之各行
  ——⛔ **未新增第三套規則**。
- **套用序**：先投影、後正規化。
