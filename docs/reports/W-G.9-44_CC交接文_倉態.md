## §六 環境與陷阱

- 🔴 **Windows／Git Bash**：CRLF 混合 ⇒ 整行錨比對兩側先 `tr -d '\r'`。
  **cp950 輸出陷阱**：python 印 emoji 會 `UnicodeEncodeError` ⇒ `export PYTHONIOENCODING=utf-8`。
- ⚠️ **heredoc 內含大量全形／emoji 之 python 易被 bash 誤剖** ⇒ 改寫成 scratchpad 之 `.py` 再跑。
- 相依：`shapely 2.1.2`／`ezdxf 1.4.3`／`pandas 2.3.3`／`numpy 2.4.4`
- 🔒 **`REAL_rc`**：⛔ 不以背景 exit code 判成敗。
- 🔒 log 檔名須含**產生它之 commit 短碼**，⛔ 不覆寫任何既有 log。
- 🔒 `verify/out/` ⛔ 禁 `git add -A`／`.` ——逐檔 `git add`。
- ⚠️ `run_step_g` **整批呼叫會於 R2 中止** ⇒ 需逐街廓各自一個 `try`（考古 70 家法）。
- 🔒 **浮點**：「等價」⛔ 不等於「逐位元相同」——生產碼之弦長式係**精確比較**（`t0 == T`），
  重現其框時**須連 `numpy` 之運算次序一起重現**（`W-G.9-42` 實測差 `1.485e-07`）。
