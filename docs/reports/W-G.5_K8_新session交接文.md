## 七、🔑 本 session 血訓（失敗考古 #34–#37·**新 session 先讀**）

### #34 「改完零 diff」有兩種**完全相反**的解釋
(甲) 真純加性／(乙) 改的東西沒人用——**二者產生一模一樣的觀測值**。

### #35 名目 diff 全空，仍可有 22 項 PASS→FAIL
名目 diff 治「測項增減」，**不治「狀態翻轉」**。兩者都要做。

### #36 跨 commit 引錨未重 grep ＋ **陳舊註解變成下一個人的錯誤前提**
三個獨立實例（`:1122` 指錯行／「單一快照鍵」／「貪婪 1:1」）。
**改機制時，把舊機制的名字從註解裡一併改掉**——否則舊名會活得比舊碼久。

### #37 一個**從未生效**的 patch，其註解會取得與生效者相同的可信度
**凡 patch 註解宣稱「改用 X」，必須同時指出 X 的寫入點與該值的讀取點。**
**影響力分析的最小單位是讀取點、不是執行點。**
我錯在追到「這個值恆被走到」就停，沒再追一步「**這個值有沒有人用**」。
