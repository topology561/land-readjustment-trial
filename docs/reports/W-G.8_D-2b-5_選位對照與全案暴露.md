## 三、🔑 §三 `100.02` 歸因 —— **結案·差額歸零**

**實料**：`verify/out/probe_D2b5_attrib.log`（入庫）　**探針**：`verify/probes/probe_D2b5_attrib.py`

### 3-1 逐位結算（`0m R1 left`·2 宗）

| 項 | 值 |
|---|---|
| 第 1 宗 `W_far_raw` | `6.463265173` → `round2` **`6.46`** |
| `R(W1_raw)` | `52.640611486` |
| `R(W1_round2)` | `52.622000000` |
| `Rw1_raw` → 2dp | `52.640611486` → `52.64` |
| `Rw2_raw` → 2dp | `47.378000000` → `47.38` |
| **`Σround(Rw,2)`** | **`100.0200`** |
| 精確 `R(W_n) − R(W_0)` | `100.000000000` |
| **總誤差** | **`+0.020000000`** |

**分解**：`B`（表放大）**`+0.018611486`**（**93.1%**）　＋　`−A`（`Rw` 2dp）`+0.001388514`
🔒 **差額歸零檢查**：`|(總誤差) − (B − A)| = ` **`0.000000000000`**

### 3-2 候選之逐一排除（§三-2·⛔ 非只驗到一個說得通的就收）

| # | 候選 | 判定 | 排除／採納依據 |
|---|---|---|---|
| A | `Rw(%)` 2dp 捨入 | **部分**（6.9%） | 2 宗上界 `0.010` **< 實測 `0.020`** ⇒ **單獨不足**（施工單 §三 已指出·**確認**） |
| **B** | **`W` 2dp 經表放大** | ✅ **主因**（93.1%） | 交棒值 ＝ `round(W_far,2)`；`R(6.463265173) − R(6.46) = +0.018611486`。實測 14 筆真鏈續中，**凡起點皆 `== round(前一宗 W_far, 2)`** |
| C | `R(W)` 表內插本身 | ⛔ **排除** | 上式**全程以同一表函式** `rw_from_width` 計算並逐位閉合、**無殘項** |
| D | `W₀` 種子 | ⛔ **排除** | `W_0 = 0`，於 `Σround(Rw,2)` 與精確式**同用**、不入差額 |

### 3-3 成因（碼面定位）

`solve_G_binary` 回傳 `'W_far': round(W_conv, 2)`（**2dp 顯示值**），而 stepg 之推進以
`_W_prev_left = float(res.get('W_far', ...))` **取該顯示值**作下一宗之鏈起點
⇒ **交棒時被降精度**，其 ≤`0.005 m` 量化誤差再經 `rw_from_width` 之**斜率放大**
（@`W≈6.46` ≈ **`5.70 %/m`**）。

### 3-4 符號（§三-4·正面陳述）

由 **短收 `99.10`** 翻為 **超收 `100.02`**——**性質已不同**：
前者是**帳務漏項**（`GB-46`·已由 `K-9-5-6` 修復），後者是**量化超收**。
⛔ 二者**非同一現象之大小變化**，不得合併敘述。

### 3-5 解析上界（⛔ 不以本案宗數硬編）

```
|ΣRw − [R(W_n) − R(W_0)]|  ≤  (n−1)·0.005·max|R'|  +  n·0.005
                                └─ 交棒降精度 ─┘      └─ Rw 2dp ─┘
```

`max|R'| = ` **`17.4000 %/m`**（@`W≈0.242 m`·數值掃描 1e-3 步長）。

| n | 上界 |
|---|---|
| 2 | `0.0970 %` |
| **3** | **`0.1890 %`** 🔴 **已超三閘容差 `0.1`** |
| 5 | `0.3730 %` 🔴 |
| 10 | `0.8330 %` 🔴 |

🔴 **結論（§三-5 之判定）：⛔ 這<u>不是</u>量化必然，是<u>可修之缺陷</u>**
——交棒若改用**全精度 `W_far_raw`**（本批已曝為純加性欄），`B` 項**整項消失**，
上界降為 `n·0.005`（`n=10` ⇒ `0.05 % < 0.1`）。
⇒ **現況 `n ≥ 3` 即可能單憑量化撞破三閘之 `0.1`** ⇒ **建議修**。
⛔ **本批未授權改**（§〇 明定本批不改生產碼行為）⇒ **上呈**。
⛔ 因其可修，**不**依 §三-5 前半記入正典為「已知量化殘差之上界」——
記之等於把**可修缺陷**追認為**常態**。
