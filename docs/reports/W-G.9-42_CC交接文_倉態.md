### 失手（⛔ 具名）

1. **「量測器之母體含其自身輸出」在同一批內犯兩次**（`CLAUDE.md` 已載此形狀）。
   🔒 修法：**凡「現查倉內有無 X」之量測，母體一律取 `git show <base>:<path>`**，
   ⛔ 不取 working tree——除非該量測之受詞**就是**「本批改完之後」。
2. **首版以 grep／awk 之行首字元判「是否可執行行」**，把三行 docstring 續行誤報。
   🔒 修法：該類判定一律走 **AST**（`verify/tools/wg942_ast_zero_delta.py`）。
3. **碎片判準 `== 3` 漏掉更退化者**（2 邊）。
4. **首版 `(s,t)` 框以純 Python 逐項乘加**（生產碼用 `numpy @`）⇒ 差 1.485e-07。
   🔒 **「等價」在浮點上不等於「逐位元相同」**；生產碼之弦長式係精確比較（`t0 == T`），
   對最後幾個 ulp 敏感 ⇒ **連運算次序一起重現**。
