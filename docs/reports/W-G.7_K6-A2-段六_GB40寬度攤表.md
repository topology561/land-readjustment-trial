## 三、🔴 §7-0 之實證：**帶底差推不出寬度差**（log `:57`〜`:81`）

施工單 §7-0 令「⛔ 禁以帶底差乘任何係數推估寬度差」。本批**以實測坐實**：

| 量級族 | 格 | `Δ寬 ÷ Δ帶底` |
|---|---|---:|
| **`10³` 級** | `R4/left` | −2359.0870 |
| | `R1/left` | −2150.8449 |
| | `R1/right` | −2127.6549 |
| 中間 | `R6/right` | −20.0418 |
| **`10⁻²` 級** | `R5/left` | −0.0757 |
| | `R2/left` | −0.0756 |
| | `R4/right` | −0.0501 |

**全距 `0.0501 〜 2359.0870`——跨 `4.71e+04` 倍**（log `:75`）。

- 低端數格恰與 **GB-33** 所載之 `|k| ≤ 0.0756` **同量級**（R2/left 之 `−0.0756` 與其逐位相同）；
- 高端數格達 `10³` ⇒ **帶底差 1 mm 可致寬度差逾 2 m**。
- ⇒ 若照 GB-33 之 `0.0756` 推估，該類格將**低估約四個數量級**。

🔴 **⇒ §7-0 之禁令成立，且理由比預想的強**：二者不只是「係數未知」，
而是**根本不存在單一係數**。⛔ 亦**不得**反過來拿本表任一比值當新係數用。

**機制（依碼·非臆測）**：`R1` 之 `∠(SIDE, ALLOC)` 落在正典所載之 `0.000°〜4.322°` 之**下端**
⇒ 虛擬塊於深端收斂為**極銳之尖角**；`parcel_min_width_n14` 之 min 恰取於帶底
⇒ 帶底沿尖角移動 1 mm，弦長變化被 `1/tan(半角)` 放大。
