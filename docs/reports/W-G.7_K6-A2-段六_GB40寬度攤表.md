## 三、🔴 §7-0 之實證：**一個機制、一個門檻**（log `:57`〜`:81`）

> 🔧 **本節已改寫（KL 2026-08-06 指正）**。初版之機制敘述**與數不合**且結論過寬，
> 原文存查於 §三-4。

施工單 §7-0 令「⛔ 禁以帶底差乘任何係數推估寬度差」。**該禁令成立**——但其理由
**不是**「不存在單一係數」，而是：**存在兩個機制，由一個門檻分開。**

### 3-1 門檻 ＝ `舊帶底` 與 `新帶底` 之大小關係

| 分支 | 格（Δ帶底之號） | `Δ寬 ÷ Δ帶底` | 機制 |
|---|---|---:|---|
| **舊帶底 ≤ 新帶底**（舊帶**未**越過最淺後緣角點） | `R5/left`（+0.013833） | −0.0757 | **主線段弦斜率** |
| | `R2/left`（+0.033020） | −0.0756 | 同上 |
| | `R4/right`（+0.000067） | −0.0501 | 同上（⚠️ 見 §三-3(b)） |
| **舊帶底 > 新帶底**（舊帶**越過**最淺後緣角點·落入**末端薄片**） | `R6/right`（−0.120267） | −20.0418 | **尾坡** |
| | `R1/right`（−0.001257） | −2127.6549 | 同上 |
| | `R1/left`（−0.001094） | −2150.8449 | 同上 |
| | `R4/left`（−0.000636） | −2359.0870 | 同上 |

🔒 **主線段分支之 `0.045〜0.076` 與 GB-33 之 `|k| ≤ 0.0756` 同量級並非巧合**
——**本就是同一種量**（帶底於主線段內移動時，弦長隨深度之線性變化率）。

### 3-2 尾坡之機制與**逐格驗算**（⛔ 非臆測·CC 自行重算）

**真機制**：舊帶底越過該宗**最淺後緣角點**、落入「**兩後緣角點之間**」之末端薄片；
薄片內多邊形朝**最深角點**收斂為一點、弦長**線性趨零** ⇒ `min` 取在**崩解中的尾巴**。

⇒ **放大倍率 ＝ 尾坡 ＝ `w_old ÷ (max(_tv) − 舊帶底)`**
＝ **【C-2】右欄「E-2′ 餘裕」之倒數量級**
⇒ 🔴 **本報告之「發現 1（比值跨 4.7e4 倍）」與「發現 3（E-2′ 餘裕僅 mm 級）」
  是同一件事**，⛔ **不得再並列為兩個獨立觀測**。

**驗算**（⛔ 本表為 CC 自行重算·輸入取自凍存 log 之列印值·**本表相除·非 log 原欄**）：

| 格 | `w_old` | E-2′ 餘裕 | **預測尾坡** | 實測 `\|Δ寬÷Δ帶底\|` | 預測/實測 |
|---|---:|---:|---:|---:|---:|
| `0m R4/left` | 43.847789 | 0.018587 | **2359.06** | 2359.0870 | **1.0000** |
| `0m R6/right` | 4.810794 | 0.240038 | **20.04** | 20.0418 | **1.0000** |
| `0m R1/right` | 4.172583 | 0.001705 | 2447.26 | 2127.6549 | 1.1502 |
| `0m R1/left` | 4.142051 | 0.001692 | 2448.02 | 2150.8449 | 1.1382 |

- 前二格 **預測/實測 ＝ 1.0000** ⇒ 尾坡式**逐位命中**。
- 後二格預測**偏高約 14〜15%**：其新 `min` 已**不在帶底**、而被**帶頂之弦夾住**
  （驗證：若新 min 在尾坡上，`R1/right` 應得 `2447.26 × 0.002962 = 7.249`，
  實測 `w_new = 6.846898 < 7.249` ⇒ 確被夾住）⇒ 比值 **< 尾坡**。**方向與機制一致。**

### 3-3 三項限縮（⛔ 初版之過寬敘述）

**(a)** 初版稱「`R2/left −0.0756` 與 GB-33 逐位相同」⇒ 改為**同量級**
（`R5/left` 為 `−0.0757`，並非同一值）。
**(b)** `R4/right` 之 `−0.0501`：其**分子 `Δ寬 ＝ −0.000003`**（顯示精度 6dp）
⇒ 該比值於顯示精度下**無有效位數** ⇒ ⛔ **【C-2】全距之下界不得當精確值引用**。
**(c)** 初版稱「七格中 4 正 3 負」⇒ 應明標為 **`0m` 情境之 7 格**（全表量得 **12 格**）。

### 3-4 🔴 切換移除了病態

舊帶底**坐在薄片裡**（一個由 `depth_from_PQ` 之受詞錯誤帶來的位置）
⇒ 量得寬度對帶底之敏感度被放大 `10¹〜10³` 倍。
**新帶底坐在真實地角上**（後緣連續段之最淺端點）⇒ 敏感度**回落至弦斜率量級**（`10⁻²`）。
⇒ **`R6/right +0.221163` 與 `R1/right −0.152969` 兩個窄餘裕，在新量法下是穩定值**
——⛔ 不得以「餘裕只有 15〜22 公分、會不會翻掉」質疑之；會翻掉的是**舊**量法。

#### 🗄️ 初版原文（**存查勿刪**）

> 「**機制（依碼·非臆測）**：`R1` 之 `∠(SIDE, ALLOC)` 落在正典所載之 `0.000°〜4.322°` 之**下端**
> ⇒ 虛擬塊於深端收斂為**極銳之尖角**；⇒ 帶底沿尖角移動 1 mm，弦長變化被 `1/tan(半角)` 放大。」
> 「⇒ 二者不只是「係數未知」，而是**根本不存在單一係數**。」

**錯在哪**：銳角兩側界之弦斜率 ＝ `|cot θ₁ − cot θ₂|`，**角越小該值越小**
——方向與觀測**相反**。我把「觀測到很大」直接接上「角很小」，**未驗算該式之單調方向**。
🔑 **戒**：提出機制時，**把該機制之公式對觀測量做一次單調性檢查**
（「若我說的成因變強，觀測量該變大還是變小？」）——本例一問即破。
