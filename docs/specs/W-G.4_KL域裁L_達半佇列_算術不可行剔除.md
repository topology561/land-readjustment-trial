## 一、三段流程（canonical）

```
① ½ 前分類  →  ② ≥½ 佇列  →  ③ 算術不可行 → 依 W-7 剔最遠 → 轉補償
```

### ①　½ 前分類

以 **½線**（`mina_qu`＝MinA_區·重劃區內最小分配面積標準）分流：

| 類 | 判準 | 去向 |
|---|---|---|
| **<½** | `2×G(a′) < mina_qu` | **現金補償**（不進配地佇列）——現行已實作（`wf_f4` ½ 輪0·裁定 H/J 逐筆計價） |
| **≥½** | `2×G(a′) ≥ mina_qu` | 進 **② ≥½ 佇列** |

> ⚠️ **二口徑分明·禁互代**（既有正典）：`mina_qu`＝**½線補償**口徑（區內標準）；
> `mina[blk]`＝**配地可行性**口徑（各街廓·E1/E2 落位用）。見 `wf_f0.py:64-68`。

### ②　≥½ 佇列

進入配地調配（現行 E1 7-4 距離法 → E2 7-5 批次全域最佳化）。

### ③　算術不可行 → 剔除 → 轉補償

**「算術不可行」＝ 佇列需求群數 > 各塊可容量之和**（容量約束下窮舉無可行指派）。
現行落點＝`wf_f4:799`（`E2 7-5 批次全域最佳化不可行——停機上呈`）。

**處置（本裁定）**：不再單純停機，改為

1. **依 W-7 剔最遠**——`W-7` 既有已實作口徑＝**佇列末位**（單一類別＋距離序 ⇒ 末位即最遠；
   同距 tie-break＝`gid` 字典序·決定性）。**沿用既有實作、勿另立序**。
2. 被剔者**轉補償**，依 **§52 逐字符計價**。
3. 剔除後重判可行性；仍不可行則續剔，至可行為止（**逐次剔除·每次僅剔一群**）。

## 二、§52 逐字符計價

被剔者之補償依 **§52** 計價，**逐字符**（即逐筆按其原位置評定地價計算，
不以全戶彙總×全區均價替代）——與**裁定 H／J**（<½ 現金補償之逐筆化）**同律**：

```
補償 = Σᵢ( aᵢ × pᵢ )    pᵢ ＝ 該筆【原位置】之評定地價
```

`pᵢ` 之取法沿用裁定 J（`wf_f4._post_price_at`）：
- 原位置為**可建築街廓** Rᵢ → 該塊後街廓單價
- 原位置為**公設用地** RD/PF/G → **公設地後價** `_wavg_post`（第11號公報 P.4）
- 二者皆非 → **loud raise**（禁靜默套均價）

捨入：**末端一次**（`_money`），不逐筆捨入。
