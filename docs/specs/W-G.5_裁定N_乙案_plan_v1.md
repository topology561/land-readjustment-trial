該宗會被對「未臨街之地」課臨街負擔＝法理錯。此即甲案被推翻之根由。

`grep -n "def _advance_block_with_split" app.py verify/stepg_pipeline.py`

### 2.2 算術改動（**極小面**）

`solve_G_binary` 新增具名參數 `unfront_area: float = 0.0`（預設 0 ⇒ **既有呼叫零行為變更**）。
唯一算式改動：

```python
diff = area_geom - G_target            # 舊
diff = (area_geom + unfront_area) - G_target   # 新（乙案 N-2′）
```

**為何不需另建定點迴圈**（回應 KL「S 變 G 變 ⇒ 須定點迭代，禁一階近似」）：
現行 bisect **每輪都以當輪 `S_guess` 重算 `G_target`**（含 `−S_guess·l₂` 與 `Rw(S_guess)`），
即**已是定點求解**，非一階近似。加常數項於 LHS **不破壞單調性**
（S↑ ⇒ `area_geom`↑ 且 `G_target`↓ ⇒ `diff` 嚴格遞增），故二分仍收斂到唯一根。
⚠️ **plan 斷言·reviewer 請驗**：若 reviewer 認定現行 bisect **非**定點（例如 `Rw` 之
`W_near` 有跨輪 state），本項須改設計——**此為 BLOCKED 級**。

### 2.3 「吃不下」判定（N-2′ 之退出／遞補）

S 下界為 0（現行 `S_min, S_max = 0.0, S_max_limit` 即是·**不動**）。
「吃不下」有**兩個門檻·強者governs**：

```
(弱·算術必要條件) S ≥ 0  ⟺  unfront_area ≤ G_target(S=0) = max(0, a·(1−A·B)·(1−C))
                             # S=0 ⇒ W==W_near ⇒ Rw=0
(強·法定·N-10)    G ≥ 承接門檻 = unfront_area + min_width × 該端深度
```

**採 N-10（強者）為退出判準**——弱條件由強條件蘊含（`min_width × 深度 > 0`）。
理由：N-10 之意義即「承接後**餘下的臨街帶仍須構成合法基地**」；只滿足弱條件者
承接後 S 極小、必於 N-11 三閘被打掉，等於把問題往後推。

**「該端深度」＝ FRONT 法向量幾何縱深**（**非** `街廓分配深度_m`）——
三源交叉印證見 §8.1；且與 N-12 明令之量測軸一致。

回傳新增鍵 `'_unfront_overflow': True` ＋ `'_unfront_area'` ＋ `'_carry_threshold'`。
**禁靜默把 S 夾 0 蒙混**（no-silent-fallback）。

### 3.2 N-9 寬度

> 寬度＝基地二側境界線間、**平行 FRONTLINE** 之距離**最小值**。

- **中間宗**：左右皆 ALLOC_LINE ⇒ 恆等於 `S` ⇒ **此閘對中間宗無額外作用**
  （KL 明示）。⇒ 實作可直接取 `S`，但**不得因此省略量測**（否則末端宗走錯分支）。
- **末端／街角側宗**：一側為 SIDELINE（或末端 BLOCK 線）、另一側為 ALLOC_LINE
  ⇒ 二線**不平行** ⇒ 距離**隨深度變化** ⇒ **取 min**。

### 3.3 N-12 深度

> 深度＝自 FRONTLINE 至 BASELINE 之**垂直距離最小值**。

- **量測軸 ＝ FRONTLINE 法向量**（`rot90(d̂)`），**不是** `alloc_normal_axis`。
  🔴 **本案兩者斜交 4–5°，混用即錯**（KL 明令）。
  ⇒ 實作**新增** `_front_normal_axis(d_hat, block_poly)`（取號指向街廓內），
  **禁**沿用 `_strip_axis`／`alloc_normal_axis`。
- **量測範圍**＝該宗沿 FRONTLINE 之臨街段；街角地自 `FRONTLINE×SIDELINE 交點` 至 `pF`。
