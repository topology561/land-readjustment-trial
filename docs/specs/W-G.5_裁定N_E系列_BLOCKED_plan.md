## 一、E-9（新）量測起點 ＝ **前緣帶上緣**

### 判準
```
_front_ts = [t for t in _tv if t <= _EPS_TOUCH_FRONT]      # 法定粒度內 ⇒ 法律上「在 FRONTLINE 上」
_t_lo     = max(0.0, max(_front_ts))                        # E-1′ 已保證 _front_ts 非空
```

### 依據（**非以實測殘差定閘寬**·N-17）
`_EPS_TOUCH_FRONT = 0.01 m` ＝ **法定粒度**（實施辦法 §3 長度 2dp·KL 已裁·見 §二）。
凡 t ≤ 法定粒度之頂點，**法律上即「位於正面路街線上」**（低於記載粒度之偏移不可能被記載為「不臨街」）。
⇒ 前緣邊之**全部**頂點同屬 t=0 之等價類 ⇒ 量測帶之起點應取該等價類之**上緣**，
使 t=`_t_lo` 之弦**橫跨整條前緣**，而非只切到其一角。

### 對已鎖夾具之相容性（逐格核過·不改任何期望值）
| 夾具格 | 前緣頂點 t | `_t_lo` | 期望值 | 是否變動 |

| ④ 街角截角後 | (0,0),(4,0) 皆 0；(8,4) t=4 >0.01 | 0 | 4.0 | 不變 |
| ⑤ 截角前 | 皆 0 | 0 | 8.0 | 不變 |
| ⑥ SIDE 傾 4.322° | 皆 0 | 0 | 6−14·tan | 不變 |
| ⑦ 末端塊外傾 3° | 皆 0 | 0 | 5.0 | 不變 |
| ⑨ 梯形 | 皆 0 | 0 | 2.2 | 不變 |
